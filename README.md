Herramienta de análisis técnico en Python/Streamlit que combina varios motores de confluencia sobre un ticket:

Ondas de Elliott + Fibonacci — clasificador de la onda EN CURSO (no histórica), con proyecciones ancladas al tramo activo y soporte para correcciones complejas (W-X-Y).
Regime Detector — ADX + Choppiness, bloquea señales en mercado lateral.
Momentum Engine — RSI/MACD y divergencias.
SMC Engine — Order Blocks, Fair Value Gaps, BOS/CHOCH, liquidity sweeps.
Volume Profile — POC y Value Area.
MTF Analyzer — alineación entre 1W/1D/4H/1H.
Scoring + Risk Manager — score 0-100 explicable, entry/stop/TPs y RR.
